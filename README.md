# Soorgla plugin — Grok Build & Claude Code

Turkish law research through the hosted Soorgla MCP server (`https://mcp.soorgla.com/mcp`).

- **What it does:** semantic search over 11M+ Turkish court decisions (Yargıtay,
  Danıştay, Anayasa Mahkemesi, Sayıştay, KİK, regional and first-instance courts),
  current legislation with article history, the Official Gazette, and a few legal
  calculators (deadlines, court fees, legal interest, holidays). Every result links to
  the original text on soorgla.com.
- **Read-only:** all tools are annotated `readOnlyHint: true`; nothing is written.
- **Sign-in:** OAuth with a Soorgla account on first connect (soorgla.com). No API key,
  no local code, no hooks.
- **Network:** only `mcp.soorgla.com` (MCP) and `giris.soorgla.com` (sign-in).
